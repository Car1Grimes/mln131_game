  4·5·3·4 = phát · triển · bền · vững.

**SDG colour wheel — not used.** The UN *SDG Guidelines* (September 2023 edition, read in full)
allow informational, non-commercial use without permission, but also require: no placement "in a
coloured box" (our stage is navy), "whenever the SDG logo and/or icons are uploaded on the
internet, these guidelines must be uploaded on the same page", and the communications page requires
a disclaimer + link on all materials (the game has no post-round credits screen). These could not
be confirmed for this use, so — as instructed — the wheel is replaced by an **original, visually
distinct diagram** (three circles in amber/cyan/green; no 17-segment ring, no SDG colours or
wording), and the decisive clue became the masked official Vietnamese plan title.

**Deviations from the rev. 2 storyboard (for approval):** (1) B9 decisive: masked QĐ 622 title
instead of the SDG wheel (rights conditions above). (2) B5: no Mekong drought/salinity photo found
under an open licence; NASA's Mekong flood images describe the annual seasonal flood ("a way of
life"), so using them as an "environmental cost" would mislead. B5 now shows repair/renewables:

smoke at d1. (3) B3 uses the Mumbai fallback (no Vietnamese open-licence image found), labelled.
(4) B7 definition uses the fuller, accurate translation (19 words) rather than the 15-word
condensation.
